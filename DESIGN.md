# ActionProof console

The opening screen introduces the inbox scenario to a first-time judge. Launching any scenario gives the space back to the transaction timeline. Reset restores the introduction.

The existing CSS variables in frontend/styles.css own the console surfaces and semantic states. Mint identifies the demo launch button and the gateway heading. Red, amber and green retain their existing decision meanings. Interface text uses Inter, while counts and transaction metadata use DM Mono.

On narrow screens the workflow selector scrolls horizontally and the feeds follow in reading order. Keyboard focus uses a blue outline. Reduced motion suppresses the decorative particle network.

During a run, a status panel above the transaction timeline shows the most recent gateway decision and its reason. The panel uses the decision text as well as color to communicate the outcome.
